# TRAML 启动器 v1.0.0 正式发布

**项目名称**  
TRAML (Traveler114514 Minecraft Launcher)  

**发布日期**  
2025 年 7 月 7 日  

## 核心功能
- ✅ 原生支持 Java 版 1.12 - 1.20.4
- ✅ 集成 Forge/Fabric 安装器
- ✅ 多实例管理（独立配置/资源）
- ✅ 一键式资源包/模组管理
- ✅ 崩溃日志分析工具

## 更新内容
### 新增
- 旅行者控制台（快捷指令系统）
- 存档备份/恢复功能
- 皮肤库直连访问

### 优化
- 启动速度提升 40%
- 内存占用减少 30%
- 模组冲突检测机制
- 用户界面响应速度

### 修复
- 修复 Java 17+ 兼容性问题
- 解决部分系统字体渲染错误
- 修正账户验证流程缺陷
- 修复实例导入功能故障

## 系统要求
- 最低配置：Java 8+，4GB RAM
- 推荐配置：Java 17+，8GB RAM
- 支持系统：Windows/Linux/macOS
